### QUAL-02 — Teste SettingsToggle Sempre Skipa

**Fase:** Phase 5
**Status:** partial (blocker de verificação)

`tests/e2e/motion-accessibility.spec.ts` Group 2, linha 31:
```typescript
const toggle = page.locator('input[aria-label="Enable animations"]');
```

Após o fix WR-02 (commit d27848a), `SettingsToggle.tsx:153` usa:
```typescript
aria-label="Ativar animações"
```

O locator nunca encontra o elemento → `toggle.isVisible()` retorna false → test.skip. O comportamento real do SettingsToggle com reduced-motion não é verificado por nenhum teste automatizado.

**Fix:** Linha 31 de `tests/e2e/motion-accessibility.spec.ts`:
```typescript
const toggle = page.locator('input[aria-label="Ativar animações"]');
```
