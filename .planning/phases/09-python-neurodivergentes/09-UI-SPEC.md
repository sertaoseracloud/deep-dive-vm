## Animation & Reveal Contract

All animations are globally declared in `Layout.astro` — no new keyframes needed.

| Pattern | Trigger | Behavior |
|---------|---------|----------|
| `[data-reveal]` | IntersectionObserver threshold 0.15 | `opacity: 0 + translateY(20px)` → `opacity: 1 + translateY(0)` at 400ms `--ease-entrance` |
| `[data-revealed]` | Added by observer when element enters viewport | Activates `[data-stagger]` children animation |
| `[data-stagger]` | Parent receives `[data-revealed]` | `fade-up` animation, 400ms, staggered via `animation-delay` (0, 80, 160, ... ms) |
| `.hero-stagger-item` | Runs immediately on page load | `fade-up` 400ms, above-fold only |
| `prefers-reduced-motion` | Media query | All `[data-reveal]`, `[data-stagger]`, `.hero-stagger-item` set to `opacity: 1; transform: none; animation: none` |

**Sections that carry `data-reveal`:**
Hero (no — above fold), TrustBand (no — band div), PainPoints (yes), Method (yes), Curriculum (yes), Mentor (yes), ForWho (yes), Bonuses (yes), Pricing (yes), FAQ (yes), FinalCTA (yes).

**Sections without `data-reveal`:**
Hero (visible immediately, no observer needed), TrustBand (band, not section), UrgencyBar, NavBar, Footer, StickyCta.

**Price card stagger:** 7 includes list items use `data-stagger` with `animation-delay` starting at 0ms, incrementing 80ms per item (0, 80, 160, 240, 320, 400, 480ms).

**Module toggle animation:** CSS only — `transform: rotate(45deg)` on `.module[open] .module-toggle` at `transition: transform 0.25s`. No JS needed.
