<threat_model>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Extraction script → File system | Reads source components and writes Markdown; must enforce path sanitisation. |
| Image optimisation → CI container | Executes native `sharp` binaries; must run in sandboxed environment. |
| Playwright tests → Rendered site | Untrusted HTML could trigger XSS in headless browser; ensure CSP is enforced during tests. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01 | Injection | Frontmatter values (title, description) | mitigate | Validate each string with a Zod schema before writing the file. |
| T-02 | Tampering | Image optimisation (sharp) | mitigate | Run `sharp` inside a CI container with read‑only source mounts; verify output checksum. |
| T-03 | Information Disclosure | Playwright screenshots | accept | Screenshots are stored only in CI artifacts and are purged after the run. |
</threat_model>
