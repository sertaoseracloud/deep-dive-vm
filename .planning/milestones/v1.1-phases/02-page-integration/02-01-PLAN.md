|-----------|-----------|
| DOM → React island | CustomEvent despachado por script Astro é recebido pelo useEffect do MobileMenuMotion |
| Props Astro → React | Dados de depoimentos são objetos TypeScript literais, não input do usuário |

| ID | Categoria | Componente | Disposição | Plano de Mitigação |
|----|-----------|------------|------------|---------------------|
| T-02-01 | Tampering | CustomEvent "toggle-menu" no window | mitigate | NÃO usar event.detail para carregar dados — o evento apenas sinaliza toggle boolean; o estado isOpen é mantido exclusivamente dentro do useState do MobileMenuMotion, nunca derivado de dados externos via evento |
| T-02-02 | Tampering | Dados de depoimentos em index.astro | accept | Dados são literais TypeScript hardcoded em build-time; sem input do usuário; sem risco de injeção |
| T-02-03 | Spoofing | Script hamburger no NavBar.astro | accept | Script apenas despacha evento no window; não acessa cookies, sessão ou dados sensíveis |
| T-02-04 | Information Disclosure | localStorage (MOTION_STORAGE_KEY) | accept | Armazena apenas boolean; sem PII; sem risco de disclosure |
| T-02-SC | Tampering | Nenhuma instalação de pacote npm neste plano | accept | Sem novos pacotes; zero risco de supply chain neste plano |
