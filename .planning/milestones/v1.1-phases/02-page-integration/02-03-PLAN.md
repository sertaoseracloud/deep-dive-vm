## Fronteiras de Confiança

| Fronteira | Descrição |
|-----------|-----------|
| CSS hover → DOM | Transformação CSS pura; sem JavaScript envolvido; sem input do usuário |
| Testes → componentes | Ambiente isolado vitest/happy-dom; sem acesso a rede ou dados reais |

| ID | Categoria | Componente | Disposição | Plano de Mitigação |
|----|-----------|------------|------------|---------------------|
| T-02-09 | Denial of Service | CSS will-change: transform no .price-card | accept | will-change promove elemento para camada composta na GPU; impacto de memória mínimo para um único card; risco aceitável |
| T-02-10 | Tampering | Testes com mocks de motion/react | accept | Mocks são apenas em ambiente de teste (vitest); não afetam bundle de produção; sem risco em runtime |
| T-02-11 | Elevation of Privilege | Playwright E2E acessando DOM real | accept | Testes rodam em browser controlado (chromium headless); sem acesso a dados reais de usuários; ambiente de desenvolvimento apenas |
| T-02-12 | Information Disclosure | CSS :focus-within no price-card | accept | Indica foco visual; sem divulgação de dados; melhora acessibilidade (WCAG 2.1 AA requerido por D-SCOPE-02-D) |
