<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → hook state | User-controlled storage value flows into animation enable/disable logic |
| prefers-reduced-motion → hook state | OS-level accessibility preference must always override user localStorage value |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | localStorage "motionEnabled" value | accept | Value only controls visual animation toggle; no security impact. Parsed with JSON.parse inside try/catch — malformed values default to enabled=false (safe). |
| T-01-02 | Denial of Service | Excessive animation causing motion sickness | mitigate | useReducedMotion() from motion/react overrides localStorage; durations capped at 150 ms per D-01. |
| T-01-03 | Information Disclosure | SSR hydration mismatch leaking server state | mitigate | All window checks are guarded with typeof window !== "undefined"; useMotionEnabled returns false on server. |
</threat_model>
