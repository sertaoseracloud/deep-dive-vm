## Milestone Summary

**Key Decisions:**

- D-AUDIT-01: impeccable v2.1.9 detects only typographic antipatterns — QUAL-01 gate determined by manual inspection
- D-AUDIT-02: emulateMedia({ reducedMotion: 'reduce' }) called BEFORE page.goto() in all Playwright reduced-motion tests
- D-AUDIT-03: Lighthouse run contra http://localhost:4321 (não npm run lighthouse:ci que aponta para produção)
- HeroMotion dual-path strategy: React.Children.map (multi-child) + useRef+querySelectorAll (single-child / production)
- MotionConfig reducedMotion="user" per-component (não page-level) + useMotionEnabled() hook via useReducedMotion() para cobertura dual
- CSS + IntersectionObserver para componentes Astro (data-reveal/data-stagger) sem React adicional
