    1. Selecionar todos os elementos com document.querySelectorAll("[data-reveal]") e armazenar em revealEls
    2. Verificar if (revealEls.length > 0) antes de criar o observer
    3. Criar IntersectionObserver com threshold: 0.15
    4. Callback: para cada entry, if (entry.isIntersecting) { entry.target.setAttribute("data-revealed", ""); observer.unobserve(entry.target); }

    6. Adicionar cleanup: document.addEventListener("astro:before-swap", () => observer.disconnect(), { once: true })
