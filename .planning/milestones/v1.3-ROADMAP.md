## Key Decisions

| Decision | Outcome |
|----------|---------|
| File-based routing sem `base` | Astro nativo, sem gambiarra de config |
| hub-og.png gerado via sharp script inline | Zero dep nova, script descartado após uso |
| social-links.ts como data file separado | Configurável sem alterar código de componente |
| courses.ts como fonte única de cursos | Hub renderiza automaticamente ao adicionar novo curso |
| LP-lite pattern para coming-soon pages | EC2 como prova de conceito do scaffold |
