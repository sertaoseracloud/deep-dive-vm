## Business Requirements

### Core Objective

Elevar a qualidade das animações da landing page usando o framework impeccable (critique → animate → audit), sem alterar o design visual estabelecido. As animações devem servir o design — não redefini-lo.

### Constraints (invioláveis)

- ✓ NÃO alterar cores, tipografia, layout ou identidade visual — mantido em todo o milestone
- ✓ NÃO modificar estrutura de componentes além do estritamente necessário — mantido
- ✓ Respeitar o DESIGN.md e design.json como verdade de marca — respeitado

## ANIM — Animation Improvements

- [x] **ANIM-01**: O Hero exibe uma sequência de entrada staggered — headline, lede e CTA aparecem um após o outro (100-150ms de delay entre elementos) na primeira visita
  - **Outcome:** HeroMotion refatorado com staggerChildren:0.12 + ease array [0.25,1,0.5,1]. HeroMotionSingle usa querySelectorAll + .hero-stagger-item CSS para o path de produção. 180 testes unitários passando.
  - **Phase 4 Plan 03 — 2026-05-16**

- [x] **ANIM-02**: As seções de conteúdo principais (Método, Ementa, Testimoniais, Pricing, FAQ) têm scroll-triggered reveals com timing consistente (motion/react whileInView ou IntersectionObserver + CSS)
  - **Outcome:** data-reveal em 8 seções + IntersectionObserver script em Layout.astro. CSS [data-reveal][data-revealed] aplica fade-up via @keyframes. 6 testes unitários em Layout.test.ts.
  - **Phase 4 Plans 01-02 — 2026-05-16**

- [x] **ANIM-03**: As curvas de easing de todas as animações são padronizadas com os cubic-bezier tokens do DESIGN.md (`ease-out-quart: 0.25 1 0.5 1`) em vez de `"easeOut"` genérico
  - **Outcome:** PARTIAL — CSS vars --ease-entrance e --ease-micro criados. HeroMotion, MobileMenuMotion, CarouselMotion, Pricing.astro corrigidos. Gaps P1 restantes: Button.astro, NavBar.astro, SettingsToggle.tsx:123 — aceitos como tech debt.
  - **Phase 4 Plans 03-04-06 — 2026-05-16**

- [x] **ANIM-04**: O SettingsToggle tem transição animada ao alternar estado (spring no indicador, fade no label "Animações")
  - **Outcome:** motion.span indicador com spring {stiffness:400, damping:30} + animate.x:0/16. Label com animate.opacity 1/0.4. MotionConfig reducedMotion="user". aria-label corrigido para PT "Ativar animações" (WR-02).
  - **Phase 4 Plan 05 — 2026-05-16**

- [x] **ANIM-05**: Grupos de itens em listas e cards dentro das seções usam stagger coordenado na entrada (bônus cards, feature list do pricing)
  - **Outcome:** Bonuses.astro: 3 bonus-card com data-stagger + animation-delay 0/80/160ms. Pricing.astro: data-reveal na section + 8 li com data-stagger + animation-delay 0–560ms. 16 testes unitários confirmando stagger.
  - **Phase 4 Plan 06 — 2026-05-16**
